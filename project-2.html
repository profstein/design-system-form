Spacing

Repeat a small set of distances to group related ideas and separate sections.

Layout

Set the maximum page width, the gap between grid items, the space between sections, and the padding inside sections. These choices apply to the live example and all three exports.

Enter any positive width in pixels. This is the maximum width; the page can shrink to fit smaller screens.

Content padding sets the space inside sections. Grid gap, section spacing, and content padding use your spacing rhythm, so they stay in proportion when you change it.
